# NEXUS-77

사이버펑크 미래도시를 무대로 한 1인칭 FPS 스토리 게임 「NEXUS-77: 오버라이드」 (three.js + Vite + TypeScript).
다섯 구역(챕터)에서 다섯 명의 주인공을 차례로 플레이한다. 기획은 [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md).
나중에 Capacitor로 모바일 앱에 옮기는 것을 전제로 만든다.

> **현재 상태: v0.4 — Ch1 「배달」 · Ch2 「추격」 · Ch3 「배신」 연속 플레이 가능**
> - Ch1 카이 (`#bazaar/play`): 골목 → 정전 시장 → 옥상 보스 바이퍼 → 제로에게 인계.
> - Ch2 제로 (`#highway/play`): 톨게이트 돌파 → 렌치의 휴게소 → 호버바이크 추격 → 관제탑 점거 → 보스 앨버트로스.
> - Ch3 아이기스 (`#spire/play`): 심문 → 보안층 탈출(동행 카이) → 레이저 게이트·유나 구출 → 서버실 방어전 → 보스 크로우.
>
> 챕터는 순서대로 열리고, 결과 화면의 **다음 챕터** 버튼으로 이어서 플레이한다. URL 해시로 열면 잠금을 건너뛴다.
> 다음 단계는 [docs/ROADMAP.md](docs/ROADMAP.md).

## 빠른 시작

```bash
# Node 20+ 권장
npm install
npm run dev        # http://localhost:5173 (같은 네트워크의 폰에서도 접속 가능: --host)
npm run build      # 타입 체크 + 프로덕션 빌드 → dist/
npm run preview    # 빌드 결과 미리보기
```

WSL에서 프로젝트를 `/mnt/c/...`(Windows 디스크)에 두면 파일 변경 감지가 늦을 수 있다.
그럴 땐 `VITE_POLL=1 npm run dev`로 실행한다. `~/dev`처럼 Linux 쪽 디스크에 두면 필요 없다.

## 조작 (플레이)

| PC | 터치 | 동작 |
|---|---|---|
| `W` `A` `S` `D` | 왼쪽 화면 드래그(조이스틱) | 이동 |
| 마우스(클릭하면 포인터 잠금) | 오른쪽 화면 드래그 | 조준 |
| 좌클릭 | 사격 버튼(누른 채 드래그하면 조준도 됨) | 사격 |
| `1`–`4` / 마우스 휠 | 하단 핫바 무기 칸 탭 | 무기 교체 |
| `Q` / `F` | 핫바 장비 칸 탭 | 수류탄 / 호위 드론 |
| `E` (길게 누르기 포함) | "사용" 버튼 | 대화 · 배전함 등 상호작용 |
| `Space` / `R` | 점프 / 장전 버튼 | 점프 · 장전 |
| `Shift` | 능력 버튼 | 캐릭터 능력: 카이 대시 · 제로 오버드라이브(3초 슬로모션) · 아이기스 육각 방패(켜고 끄기, 켤 때 밀치기) |
| `A` `D` (주행 중) | 왼쪽 스틱 좌우 / ◀ ▶ 버튼 | 호버바이크 차선 변경 |
| `Space` · `Enter` · 클릭 / `1`–`3` | 대화창 탭 / 선택지 탭 | 대사 넘기기 / 선택 |
| `Esc` | 오른쪽 위 일시정지 버튼 | 일시정지(감도, 터치 자동 사격, 체크포인트 재시작) |

터치에서는 조준 보조가 기본으로 켜져 있다. 진행도(체크포인트, 기억 조각, 클리어 기록)는 `localStorage`에 저장되고, Capacitor 앱에서는 네이티브 Preferences에도 함께 저장된다(`src/game/Storage.ts`).

## 폴더 구조

```
nexus-77/
├─ index.html              # UI 오버레이(정보 패널·탭) + 캔버스
├─ vite.config.ts          # base './' → Capacitor/서브경로 배포 대응
├─ src/
│  ├─ main.ts              # UI 바인딩, 입력(키보드·스와이프·해시)
│  ├─ style.css            # 반응형 UI (세로 화면 대응 포함)
│  ├─ app/Viewer.ts        # 렌더러·루프·장면 교체·리소스 해제·품질 설정
│  ├─ engine/
│  │  ├─ SceneKit.ts       # 공용 빌더: 도시 블록, 네온 간판, 비, 빛줄기, 포털, 파티클, 휴머노이드 리그
│  │  └─ types.ts          # SceneCtx (장면 빌더 계약)
│  ├─ scenes/              # 구역별 장면 + 캐릭터 (구역 1개 = 파일 1개)
│  └─ data/districts.ts    # 구역·캐릭터 메타데이터, 팔레트, 빌더 연결
├─ public/                 # 정적 파일 (favicon 등)
└─ docs/
   ├─ GAME_DESIGN.md       # 게임 기획 초안 (수정 전제)
   └─ ROADMAP.md           # 단계별 구현 계획 + 모바일 이식 계획
```

## 장면 빌더 계약

각 구역은 `(kit: SceneKit, ctx: SceneCtx) => void` 함수 하나로 만든다.

- `ctx.scene`에 오브젝트를 추가하고, 매 프레임 할 일은 `ctx.up.push((t) => …)`로 등록한다.
- 쇼케이스할 캐릭터 루트는 `ctx.hero`에 넣는다. 턴테이블 회전에 쓰인다.
- 카메라 기본값은 `(0.4, 2.1, 7.8)`이고 `ctx.look`을 바라본다. 빌더가 바꿔도 된다(예: highway).
- 캐릭터는 대략 x≈1.8–2.1, 원점 근처에 서 있다. 키는 약 2.3 유닛이다.

새 구역을 추가하려면 `src/scenes/<id>.ts`를 만들고 `src/data/districts.ts`에 항목을 하나 넣으면 된다.

## 기술 메모

- three.js r187, WebGL 렌더러. 그림자는 `PCFShadowMap`, 톤매핑은 ACES.
- 모든 텍스처(창문, 네온 간판, 홀로 화면)는 `<canvas>`로 런타임 생성한다. 외부 에셋 파일이 0개라 번들 하나로 끝난다.
- `src/engine/SceneKit.ts`, `src/scenes/*.ts`는 디자인 데모에서 옮겨 온 코드라 `// @ts-nocheck` 상태다. 새 코드는 strict TypeScript로 쓰고, 옮겨 온 코드는 손댈 때마다 타입을 붙여 나간다.
- 저사양·터치 기기로 판단되면 픽셀 비율을 1.5로 제한하고, 안티앨리어싱을 끄고, 그림자 맵을 1024로 낮춘다(`Viewer.ts`).
- 한글 폰트는 Google Fonts(Black Han Sans, Noto Sans KR, Space Grotesk)를 쓴다. 오프라인·앱 배포 전에 `public/fonts`로 셀프 호스팅해야 한다(ROADMAP 참고).
