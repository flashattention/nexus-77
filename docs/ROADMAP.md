## 모바일 이식 (Capacitor)

웹 빌드를 그대로 감싸는 방식이다. 지금 구조에서 이미 대비해 둔 것:

- `vite.config.ts`의 `base: './'`: 앱 내부 파일 경로에서도 동작
- 외부 에셋 파일 없음(캔버스 텍스처) → 오프라인 번들 하나
- `viewport-fit=cover` + `env(safe-area-inset-*)`: 노치 대응
- 터치 입력과 저사양 품질 분기

이식할 때 할 일:

```bash
npm i @capacitor/core @capacitor/cli
npx cap init "NEXUS-77" com.flashattention.nexus77 --web-dir=dist
npm run build
npm i @capacitor/android @capacitor/ios
npx cap add android   # (iOS는 macOS에서) npx cap add ios
npx cap sync
npx cap open android
```

- 화면 방향 고정: `@capacitor/screen-orientation` 또는 네이티브 설정(플레이는 가로)
- 상태 바 숨김: `@capacitor/status-bar`
- 진동 피드백: `@capacitor/haptics` (피격·수집)
- 저장: `@capacitor/preferences`
- 앱 아이콘·스플래시: `@capacitor/assets`
